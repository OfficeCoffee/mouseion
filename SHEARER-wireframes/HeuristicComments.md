ViewAllV2:

 - Back Arrow:
	Heuristic 3: User Control and Freedom
	 - Back arrow allows user to exit view all menu and return to dash board.
	 - Revision, previous version lacked this functionality.

 - Modify(+):
	Heuristic 7: Flexibility and Efficiency of Use
	 - Modify button allows users to easily modify a word via a shortcut.
	 - Previous version had this functionality, modify was added to make this more clear.

 - Alphabetized Word List:
	Heuristic 2: Match Between the System and the Real World
	 - (Although not visible from low fidelity) words in view all will be in alphabetical order.
	 - This was unclear in previous version and clarified with group during last meeting.

DeletePopUp:

	Heuristic 5: Error Prevention
	 - This pop up prevents the user from accidentally deleting a word (destructive action).
	 - Revision, previous version lacked this feature. Deletion is a destructive action requiring an extra layer of error prevention.
