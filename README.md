**Team name:** ReverseOsmosis

**Application Name:** Custom word organizer

**Vision:** To create a place where people can organize and practice using new words.

**Mission:** To create an organizer that can capture unique words and their associated context while providing a way to consistently practice said words.

**Core User:** Logofile

**What:**

- **Search:** A specific word they want to find
- **View All:** All the words the user has made
- **Create:** A new word with context
- **Edit:** A word or a words definition/context
- **Homepage / dashboard:** A title with a start button

**When:**
- **Search:** When the user wants to find a specific word they had added
- **View All:** When the user wants to see all the words they have added
- **Create:** When the user wants to add a new word
- **Edit:** When the user wants to change a word or its definition/context
- **Homepage / dashboard:** When the user opens the application

**Why:**
- **Search:** For if the user wants to find a specific word
- **View All:** For if the user wants to see all the words they had made
- **Create:** For if the user wants to add a new word
- **Edit:** For if the user wants to change a word or its definition/context
- **Homepage / dashboard:** For the user to interact with the functionality of the application

**Where:**
- **Search:** Search bar at the top of the page
- **View All:** Widget on the side of the page 
- **Create:** Widget on the side of the page
- **Edit:** Button on the side of the word
- **Homepage / dashboard:** Starting screen

**How:**
- **Search:** User will click the search bar and type in what word they want to find
- **View All:** User will click View All widget and a list of all words will appear
- **Create:** User will click the Add widget and a new screen to add a word will appear
- **Edit:** User will click the edit button to change the word or definition/context
- **Homepage / dashboard:** User will enter page when opening application
